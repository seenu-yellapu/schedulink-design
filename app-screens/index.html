For engineers

Each page is one HTML file with no script. All styles are in _shared.css (about 40 lines) on top of the site tokens in ../assets/schedulink.css (colors, radii, fonts). Copy the two CSS files and the markup; the class names map one to one onto components: ap-card, ap-h1, ap-f (field), ap-i (input), ap-btn, ap-fine, ap-alt. Fonts are Poppins (headings) and Inter (everything else) from Google Fonts. Keep the hairline borders; no shadows anywhere. The reCAPTCHA box on Create account is a placeholder drawn at the widget's real size (304×78, light theme, normal size).
