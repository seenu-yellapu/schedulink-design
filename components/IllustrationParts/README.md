# IllustrationParts

The building blocks of ProductIllustration, shown one by one so they can be reused in feature pages, module heroes and other visuals.

- **Column header:** 42px soft tile with a blue icon, Poppins 600 title at 22px, 2px `#DCDDE1` underline across the column.
- **Photoshoot row:** event name (17px semibold), full school name with a building icon (14.5px, `#73767B`). Simplified version: name plus one placeholder line.
- **Task row:** name, school, status pill on the right. Simplified version: name, placeholder line, placeholder pill.
- **Photographer row:** 40px illustrated face, name, role, and a shoot card. Simplified version: face, name, placeholder line, placeholder shoot card.
- **Status pills:** 13px semibold, 8px corners. Overdue `#FDE8E8` on `#B42318`; Due today `#F2ECFC` on `#6A3FBF`; Due later `#EEF2FC` on `#1F43A8`. Purple is used for "due today" only, nowhere else on the site.
- **Shoot card:** 112 by 44px, `#F4F6FB` with a 1px `#E6EBF6` border and 10px corners; event in 13.5px semibold, time in 12.5px grey. Every card in a column is identical in size.
- **Illustrated faces:** simple drawn portraits on pastel circles, varied skin tones, hair and shirt colours. Never real people.
- **Placeholders:** `#ECECF0` lines and pills, 7 to 8px tall, fully rounded.
