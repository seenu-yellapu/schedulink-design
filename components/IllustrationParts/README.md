# IllustrationParts

The building blocks of ProductIllustration, shown one by one so they can be reused in feature pages, part heroes and other visuals.

- **Column header:** 42px soft tile with a blue icon, Poppins 600 title at 22px, 2px `#DCDDE1` underline across the column.
- **Photoshoot row:** event name (17px semibold), full school name with a building icon (14.5px, `ink-muted`). Simplified version: name plus one placeholder line.
- **Task row:** name, school, status pill on the right. Simplified version: name, placeholder line, placeholder pill.
- **Photographer row:** 40px illustrated face, name, role, and a shoot card. Simplified version: face, name, placeholder line, placeholder shoot card.
- **Status pills:** 13px semibold, 8px corners. Overdue `status-overdue-bg` with `status-overdue-text`; Due today `status-today-bg` with `status-today-text`; Due later `status-later-bg` with `status-later-text`. Purple is used for "due today" only, nowhere else on the site.
- **Shoot card:** 112 by 44px, `illus-shootcard` with a 1px `illus-shootcard-line` border and 10px corners; event in 13.5px semibold, time in 12.5px grey. Every card in a column is identical in size.
- **Illustrated faces:** simple drawn portraits on pastel circles, varied skin tones, hair and shirt colours. Never real people.
- **Placeholders:** `#ECECF0` lines and pills, 7 to 8px tall, fully rounded.
