# Logo

The ScheduLink wordmark and icon, in the variants the site uses. Files are stored in this design system, so pull them from here rather than from a Drive folder.

Guidelines:

- Nav uses the wordmark at 28px tall. Footer and any `surface-invert` band use the white wordmark at the same height.
- Clear space on every side is at least the height of the S in the wordmark.
- The icon is for the favicon, app icon and avatars. Don't use it in place of the wordmark on the website.
- Never recolour, outline, stretch, rotate or shadow either mark. On mid-tone photography, place the white wordmark on a solid `brand` or `ink` band rather than directly on the image.
- Minimum wordmark width is 120px. Below that, use the icon.
