# FeatureCard

The card used for the three value props and for each part in the "How studios run with ScheduLink" grid.

Guidelines:

- `surface-raised` fill, 1px `line` border, `radius-lg`, `space-6` padding, a 1px `line` border. Linked cards take a `line-strong` border and a `brand` border on hover.
- Icon plate: 44px square, `brand-soft` fill, `radius-md`, holding a 24px line icon in `brand` at 1.5px stroke.
- Title in `subheading`, `ink`. Body in `body-s`, `ink-secondary`, two or three lines. Anything longer belongs on the feature page.
- Optional quiet link at the bottom, from the Button component.
- Three per row on desktop, one per row on mobile, `space-6` gap. Let the grid equalise heights rather than padding copy to match.
- No left accent border, no emoji in place of icons, no number badges.
